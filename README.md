# PixPurge

**PixPurge** is a web app that removes text, captions, watermarks, and date stamps from images with AI.

**Try it: [pixpurge.com](https://pixpurge.com)**

Upload a photo and the AI detects every text region, erases it, and rebuilds the background underneath — you preview the result in seconds and download it in the original resolution, with no watermark added.

## Highlights

- **One-click cleanup** — the AI scans the whole image, finds the text, and removes it automatically.
- **Manual precision mode** — brush, box, or lasso the area you want cleaned; only that region is processed, and every pixel outside it stays untouched.
- **Runs in your browser** — no installs, no plugins. JPG, PNG, WebP, and HEIC files up to 10MB, on desktop or mobile.
- **Privacy first** — images travel over an encrypted connection and are never used to train models.
- **Start with free monthly credits** — every new account gets monthly credits; more processing power is available through one-time credit packs or monthly plans.

## About this repository

The front-end source of the PixPurge web app: a static site (HTML + Tailwind CSS + vanilla JavaScript, no framework) with the embedded tool UI, deployed on Vercel.
